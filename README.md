# Fewer Tasks, Same Ranking?

Cheaper coding-agent evaluation that holds up over time.

A small subset of benchmark tasks can rank agents almost like the full benchmark, but prior work tests
this on the same agents it selects from. We select subsets from older or weaker agents' results and
check whether they still rank newer and stronger agents, on SWE-bench Verified and Terminal-Bench 2.0.

- [ROADMAP.md](ROADMAP.md): plan, core claims, data, roles and timeline.
- [BACKGROUND.md](BACKGROUND.md): prior work and concepts (IRT, Kendall tau, noise ceiling, decay curve).

11-768 AI Agents, Fall 2026, Carnegie Mellon University.
